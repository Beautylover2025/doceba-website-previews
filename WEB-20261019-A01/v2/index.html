Gut zu wissen

Brauche ich einen Termin?

Nein. Kommen Sie während der Öffnungszeiten vorbei oder rufen Sie vorher kurz an.

Wie lange dauert eine Änderung?

Das hängt vom Aufwand ab. Beim Abstecken sagen wir Ihnen, wann Ihr Stück fertig ist.

Wie läuft die Abholung?

Zur Abholung probieren Sie das Stück noch einmal an. Sitzt etwas nicht, bessern wir direkt nach.

Was soll ich mitbringen?

Das Kleidungsstück und, wenn möglich, die Schuhe, die Sie dazu tragen. So stimmt die Länge gleich.
