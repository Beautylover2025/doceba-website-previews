Herren

Der Meister

Dilo, Friseurmeister.

Hinter Diamonds steht Friseurmeister Dilo. Er schneidet selbst, nimmt sich Zeit für die Details und achtet darauf, dass Sie den Salon so verlassen, wie Sie ihn sich vorgestellt haben.

Ob ein präziser Fade, ein weicher Damenschnitt oder einfach ein frischer Look: Hier bekommen Sie Handwerk, das man sieht.
